Submit a New Material

Fill in as many fields as you have data for. Download the JSON and submit it as a GitHub Pull Request for admin review.

Next steps — submit via GitHub Pull Request

  1. Fork the repository at scroberts/Engineering-Materials-Database
  2. Place your JSON file in the correct subfolder:
    materials/metals/, materials/plastics/, materials/ceramics/, or materials/composites/
  3. Name the file exactly as the slug — e.g. your-material-slug.json
  4. Open a Pull Request with the title format:
    Add material: Material Name
  5. The GitHub Actions CI will validate your JSON automatically. An admin will review and merge once everything checks out.
